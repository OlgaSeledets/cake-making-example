# SweetCake — торты на заказ

Демонстрационный рекламный лендинг для портфолио. HTML, CSS, TypeScript. Не использует фреймворки и не требует серверной части.

## Состав проекта

- `index.html` — семантическая разметка страницы.
- `assets/css/styles.css` — дизайн, адаптив, анимации, фокус-стили.
- `assets/img/` — качественные локальные фотографии WebP.
- `assets/decor-leaves.svg` — декоративная иллюстрация.
- `src/main.ts` — логика меню, слайдера, модалки и подсказки для демонстрационных контактов.
- `assets/js/main.js` — скомпилированный JavaScript, уже готовый к публикации.
- `.github/workflows/deploy.yml` — автоматическая публикация в GitHub Pages.

## Быстрый просмотр

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Публикация GitHub Pages

1. Создайте репозиторий GitHub.
2. Загрузите **содержимое этой папки**, включая скрытую папку `.github`, в корень репозитория. Файл `index.html` должен лежать в корне.
3. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Сделайте `push` в `main` или запустите **Actions → Deploy SweetCake to GitHub Pages → Run workflow**.
5. После успешной сборки адрес будет вида `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Workflow устанавливает TypeScript, компилирует `src/main.ts` и публикует `index.html` и `assets/`.

## Настройка контактов

Пока кнопки Telegram и WhatsApp — демонстрационные. Для настройки:

1. В `index.html` замените `https://t.me/USERNAME` и `https://wa.me/79990000000` на свои ссылки.
2. Удалите у ссылок атрибуты `data-demo-contact="Telegram"` и `data-demo-contact="WhatsApp"`, чтобы они перестали показывать демонстрационную подсказку и начали переходить по указанным адресам.

Серверная форма не нужна: контакты открываются в мессенджере.

## Разработка

Для редактирования TypeScript:

```bash
npm install
npm run build
```

`npm run typecheck` запускает проверку типов без сборки. Изображения и иконки локальные, без внешних CDN-зависимостей.

## Доступность

Семантическая структура, язык `ru`, ссылка «Перейти к содержимому», альтернативный текст изображений, видимый `:focus-visible`, доступное мобильное меню (`aria-expanded`, `aria-controls`, `inert`), клавиатурное управление каруселью, модальное окно `<dialog>` с Escape и возвратом фокуса, статусные сообщения `aria-live`, а также `prefers-reduced-motion`.

## Примечание

Проект демонстрационный. SweetCake — условный бренд, изображения тортов созданы для макета. Реальных заказов, адресов, цен, отзывов и коммерческих обещаний сайт не содержит.
