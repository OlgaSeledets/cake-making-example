# SweetCake — демонстрационный лендинг

Адаптивный рекламный сайт тортов на заказ. HTML + CSS + TypeScript, без фреймворков. Готов для публикации на GitHub Pages.

## Как посмотреть

Откройте `index.html` в браузере. Для локальной проверки через сервер можно выполнить `python -m http.server 8080`, затем открыть `http://localhost:8080`.

## Как опубликовать на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub, например `sweetcake`.
2. Загрузите в корень репозитория **всё содержимое** этой папки (включая `index.html`, `assets`, `src`, `package.json`). Не загружайте дополнительную внешнюю папку-обёртку.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
5. Сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/sweetcake/` (имя репозитория подставьте своё).

GitHub Pages отдаёт готовый `assets/js/main.js`, поэтому сборка на сервере не требуется.

## Как заменить контакты

Найдите в `index.html` `https://t.me/USERNAME` и `https://wa.me/79990000000` и замените на настоящие ссылки. Контакты пока демонстрационные: скрипт `src/main.ts` специально перехватывает их и показывает уведомление, чтобы посетитель не попал на посторонний номер. **Чтобы включить переходы после замены ссылок**, удалите обработчик в конце `src/main.ts`, начинающийся с `document.querySelectorAll<HTMLAnchorElement>('[data-demo-contact]')`, затем пересоберите JS. Либо удалите атрибуты `data-demo-contact` у соответствующих ссылок в `index.html` — тогда переходы начнут работать без пересборки.

## Разработка

- `index.html` — контент и семантическая разметка.
- `assets/css/styles.css` — дизайн и адаптив.
- `src/main.ts` — меню, слайдер, модальное окно, анимации.
- `assets/js/main.js` — готовый скомпилированный JS (уже включён в архив).
- `assets/img` — локальные изображения WebP.

Для изменений в TS установите TypeScript (`npm install`), затем `npm run build`. Без изменения TS установка зависимостей не нужна.

## Доступность

Семантические разделы и заголовки, skip link, контрастные фокус-стили, доступное мобильное меню (`aria-expanded`, `aria-controls`), подписи кнопок, клавиатурная навигация по карусели, `<dialog>` с закрытием по Escape и возвратом фокуса, `alt` у изображений, `prefers-reduced-motion`.

## Важно

Это **учебный/портфолио-проект**, бренд и тексты вымышленные. Изображения являются сгенерированными иллюстрациями, вырезанными из утверждённой дизайн-концепции. Никаких вымышленных отзывов, цен, адреса или реквизитов не представлено. Подключаемые через Google Fonts шрифты требуют интернета; без него используются системные альтернативы.
